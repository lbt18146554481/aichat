# Compamore 品牌与图标使用说明

**版本：BLUE 02 · 2026-10-28**  
**品牌主张：Compassion · Kindness · Love**  
**品牌标语：Where kindness meets love.**

本版将主色收敛为更纯净、克制的天青蓝。设计规范、矢量母版、PNG、Xcode 配置、Website 配置和社交素材均已同步更新。

## 1. 先打开什么

- **查看或修改设计**：打开 `Compamore品牌图标系统.kanva.pptd` 文件卡片，在编辑器中预览、编辑，并导出图片或 PPTX。
- **开发接入**：解压 `Compamore品牌图标素材包.zip`，按下表选择 `assets/` 中的文件。
- **查找详细规范**：设计稿包含品牌概念、Logo 家族、色彩字体、iOS、Website、社交分享、英文参考和快速使用，共 9 页。

## 2. 按用途选择文件

## 3. iOS 接入

### Icon Composer

- 默认外观：`background-default.svg` + `foreground-default.svg`，或使用对应 1024 PNG 前景层。
- 深色外观：`background-dark.svg` + `foreground-dark.svg`。
- Clear／Tinted：使用 `foreground-mono-black-*` 与 `foreground-mono-white-*`，在工具中配置系统外观。
- `compamore-ios-clear-*` 与 `compamore-ios-tinted-*` 的扁平 PNG 是**外观预览图**，生产接入使用 `layers/`。

### 传统 Asset Catalog

将 `assets/ios/AppIcon.appiconset/` 整个目录加入 Xcode。扁平 App Store 图标为不透明 RGB 方形母版；**不要预先添加圆角、裁切或系统遮罩**。

## 4. Website／PWA 接入

1. 将 `assets/web/` 内的文件与 `icons/` 子目录复制到网站公开根目录。
2. 将 `html-snippet.html` 中的标签加入 HTML `<head>`。
3. 按部署环境调整 `manifest.webmanifest` 的 `start_url`、`scope`、`id`。
4. 若部署在子路径，同步修改 Manifest、HTML 与 `browserconfig.xml` 中以 `/` 开头的 URL。
5. `icon-maskable-*` 已保留核心图形安全区，请继续使用 `purpose: "maskable"`。

Open Graph 示例：

```html
<meta property="og:image" content="https://你的域名/compamore-og-image.png">
<meta property="og:image:width" content="1200">
<meta property="og:image:height" content="630">
<meta property="og:image:alt" content="Compamore — Where kindness meets love.">
```

## 6. 品牌使用规则

- Logo 四周至少保留一个内圆点直径的净空。
- 横版 Logo 建议最小宽度 120 px。
- 16–32 px 使用专用 Micro／favicon，不要直接缩小完整字标。
- 浅色背景使用 Primary；深色背景使用 Reversed；单色场景使用 Mono Navy 或 Mono White。
- 不重染、不拉伸、不倾斜、不改变圆点位置，不添加描边、阴影或额外图形。
- Clear 外观中的中性灰属于系统外观预览，不是遗漏的品牌色。
