# Compamore — Brand & Platform Icon System

## Style plan
- Revision: BLUE 02 / 2026-10-28 — refined pure azure palette; all production assets and slide previews synchronized.
- Style name: Clear Quiet Modernism / 清澈静谧现代主义
- Keywords: embrace, clarity, trust
- Description: 以开放几何、充足留白和清澈蓝色建立国际化亲和力与可信感。核心符号不使用性别化人物、火焰或复杂爱心，而以开放 C 形与独立圆形表达接纳、回应和完整自我。
- Font plan: Manrope SemiBold for the English wordmark; Manrope for English supporting text; MiSans for Chinese supporting text. Wordmark assets are outlined for portability.
- Color scheme: Compassion Blue #2477B8; Deep Connection #1F6FAE; Icon Gradient Top #3D99D4; Cloud Blue #D2E9F5; Trust Navy #1F2D3D; Cloud White #F7FAFC; Soft Mist #EDF3F7; Pure White #FFFFFF.
- Layout plan: 16:9 editorial boards with large symbol fields, disciplined grids, short bilingual labels, and real-context icon previews. No decorative clutter.
- Core visual requirements: two-shape Open Embrace mark; rounded terminals; optically centered symbol; flat logo masters; subtle sky-to-deep-blue app background; unmasked square iOS masters; dedicated maskable safe-zone version; legible micro mark for favicon.

## Brand idea
The Open Embrace / 开放的拥抱
- Open C: compassion that leaves room for another person.
- Independent circle: a complete individual, welcomed as they are.
- Relationship: kindness expressed through an open, respectful response.
- Optional line: Where kindness meets love.

## Production principles
- Master logo artwork remains editable and vector-based.
- iOS square masters are exported without pre-applied corner masks.
- Provide Default, Dark, Clear and Tinted design assets while preserving the same core geometry.
- Provide SVG, outlined SVG, transparent PNG, flattened RGB PNG and multi-size ICO as appropriate.
- Small-size favicon uses an optically strengthened micro mark.
